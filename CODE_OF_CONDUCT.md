# Code of Conduct

## Standar kami

Kami ingin setiap orang dapat berkontribusi tanpa pelecehan, intimidasi, diskriminasi, atau serangan pribadi. Diskusi teknis boleh tegas, tetapi harus tetap membahas kode, bukti, dan dampak perubahan.

Perilaku yang diharapkan:

- Menjelaskan perbedaan pendapat dengan bahasa yang tenang.
- Menerima koreksi dan mengutamakan bukti.
- Menghormati privasi, waktu, dan tingkat pengalaman kontributor lain.
- Menjaga issue dan pull request tetap relevan dengan proyek.

Perilaku yang tidak dapat diterima:

- Pelecehan, ancaman, ujaran kebencian, atau diskriminasi.
- Membagikan data pribadi, kredensial, atau QRIS privat.
- Spam, trolling, atau sengaja mengganggu proses kontribusi.

## Penegakan

Laporkan perilaku yang tidak dapat diterima secara privat kepada maintainer repository melalui kanal kontak yang tercantum di profil GitHub pemilik repository. Sertakan tautan issue atau pull request, ringkasan kejadian, dan bukti yang relevan. Jangan membagikan secret dalam laporan.

Maintainer dapat menghapus komentar, meminta perubahan, menutup thread, atau membatasi kontribusi untuk menjaga ruang kerja tetap aman.
