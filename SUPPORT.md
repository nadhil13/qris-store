# Support

## Before asking

Periksa [README.md](README.md), [DEMO.md](DEMO.md), dan [DEPLOYMENT.md](DEPLOYMENT.md). Pastikan masalah dapat direproduksi melalui HTTP server, bukan dengan membuka file menggunakan `file://`.

## Bug reports

Gunakan template bug report dan sertakan browser, viewport, langkah reproduksi, expected result, actual result, serta console error yang tidak mengandung data sensitif.

## Feature requests

Jelaskan masalah pengguna dan hasil yang diinginkan. Sertakan dampak pada mobile, accessibility, checkout, QRIS, atau admin bila relevan.

## Security

Jangan gunakan issue publik untuk secret, exploit, data pelanggan, atau kelemahan pembayaran. Ikuti [SECURITY.md](SECURITY.md).
